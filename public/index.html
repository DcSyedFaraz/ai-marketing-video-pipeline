Split Screen Layout

  • Output is always portrait 1080×1920 (9:16)
  • Both videos play simultaneously
  • Portrait + Portrait: side-by-side, each 540px wide
  • Landscape podcast + Portrait UGC: podcast top 1/3 (640px) · UGC bottom 2/3 (1280px)
  • Portrait podcast + Landscape UGC: podcast top 2/3 (1280px) · UGC bottom 1/3 (640px)
  • Both landscape: podcast top 1/3 · UGC bottom 2/3

Duration Handling

  • If podcast ends first → UGC plays full screen for the remainder
  • If UGC ends first → podcast plays full screen for the remainder
  • Total output = duration of the longer video

Music

  • Music is mixed softly under both video audio tracks
  • Choose an existing file from uploads or upload a new one
  • Volume slider controls music level (5%–50%)
